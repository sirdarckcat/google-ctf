GPU FWHT benchmark

Measures a 224-point uint32 Walsh–Hadamard transform — the inner loop of the sphinx key-recovery attack — on the GPU via both WebGL2 and WebGPU, and compares them against a WebAssembly CPU baseline on this same machine. WebGL2 is the one that usually works: it is available almost everywhere, whereas WebGPU is still gated per driver on Android. Everything, including any driver errors, lands in the box below.

Runs automatically, then press Copy all output. Served as a top-level HTTPS page, so if this still reports no usable adapter, the cause is the device or its driver rather than the page context — the log says which and what to check.
